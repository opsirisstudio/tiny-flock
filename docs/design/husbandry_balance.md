# Provisional husbandry balance

All values below are **Milestone 5 prototype values** centralized in `HusbandryConfig`, not final tuning.

| Rule | Value |
|---|---:|
| Fully fed to empty | 2 active game days |
| Fully clean to dirty | 4 active game days |
| Staple feed restoration | 0.45 |
| Treat feed restoration | 0.20 |
| Base feed happiness / bond | 0.03 / 0.01 |
| Favorite happiness / bond bonus | 0.08 / 0.03 |
| Pet happiness / bond | 0.08 / 0.04 |
| Groom cleanliness / happiness / bond | 0.45 / 0.05 / 0.02 |
| Wash cleanliness / base happiness / bond | 0.80 / 0.01 / 0.01 |
| Happiness movement | at most 0.35 per active day |
| Breeding hunger / happiness minimum | 0.40 / 0.40 |
| Wool care minimum | 0.50 |

Treats are emotionally useful but less filling than staples. Lamb care bond is ×1.20 and elder petting bond ×1.10. No age group has accelerated hunger or permanent penalties.
