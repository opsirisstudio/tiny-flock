# Lifecycle simulation prototype balance

These are centralized **prototype balancing values**, not permanent design decisions.

| Value | Prototype setting |
|---|---:|
| Lamb | 0 through before day 7 |
| Juvenile | day 7 through before day 14 |
| Adult | day 14 through before day 90 |
| Elder | day 90 onward |
| Pregnancy | 3 game days |
| Litter | singleton 0.70; twins 0.25; triplets 0.05 |
| Lamb sex | female 0.50; male 0.50 |
| Female postpartum cooldown | 2 game days after birth |
| Male cooldown | none |
| Full wool growth | 5 game days |
