# Legacy system

- **FOUNDER** is explicit persistent metadata on every original founder.
- **MUTATION_FOUNDER** is assigned only when a lamb's breeding mutation result reports an actual new allele change. Its event records locus and before/after pairs. Normal inheritance does not qualify.
- **NOTABLE_BREEDER** remains explicit/manual metadata. Future deterministic rules might consider descendant depth or confirmed rare lineages, but none are implemented.

Tags do not alter genetics or behavior.
